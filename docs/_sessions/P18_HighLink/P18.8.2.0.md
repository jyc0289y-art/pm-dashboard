## 작업 요약
P18.8.1.0 종료 후 사용자가 대시보드에서 영상이 흰 화면으로만 보이는 문제 보고. 원인 진단 결과 Streamlit 1.56부터 내장 서버가 Tornado→Starlette로 전환되어 `tornado_mjpeg.py`의 Tornado 핸들러 패치가 silent fail (TRAP-012). 핫픽스(`st.image()` placeholder)로 단일 영상 임시 표시 후, 옵션 B(:8503 standalone MJPEG + bootstrap 스크립트)로 본격 해결하여 멀티 카메라 그리드까지 정상 작동하도록 함.

## 주요 결과물

### 진단
- `curl http://localhost:8501/mjpeg/snapshot`이 JPEG 대신 Streamlit React index.html 반환 → 핸들러 미등록 확인
- `streamlit.web.server.server.Server` 클래스에 `_create_app`, `_start_starlette` 메서드 발견 → Starlette 기반
- Tornado Application이 더 이상 존재하지 않으므로 `wildcard_router.rules` 패치 시도가 silent fail

### 핫픽스 (commit 371323c)
- Mode C iframe 제거 → `st.empty()` placeholder + `placeholder.image(annotated)` 매 프레임 갱신
- 단일 영상은 보이지만 5~10fps 한계, 멀티 카메라 그리드는 여전히 작동 안 함

### 옵션 B 적용 (commit 7d21e3d)
- **신규 `run_highlink.py`**: bootstrap 스크립트
  - streamlit CLI 실행 *전*에 `stream_server.start(8503)` 호출
  - 같은 Python 프로세스 → `sys.modules` 공유 → `_latest_jpeg` 메모리 공유 보장
- `stream_server.py`: 기본 포트 8503, 모듈 import 시 자동 시작
- `app.py` Mode C: iframe 복원 + 절대 URL `http://localhost:8503/viewer`, placeholder 핫픽스 제거
- `camera_grid.py`: `/mjpeg/snapshot|/stream` → `http://localhost:8503/...`

### 포트 :8502 → :8503 변경 사유
- macOS 일부 환경에서 :8502가 시스템 레벨로 차단되어 있음
- `lsof -nP -iTCP:8502`는 미점유로 표시되지만 socket bind 시 OSError [Errno 48] 발생
- :8503은 정상 작동 확인

## 핵심 결정사항
1. **옵션 B 우선 적용** — 옵션 A(Starlette 미들웨어 재작성)보다 30분 작업으로 즉시 효과
2. **bootstrap 스크립트 방식** — `streamlit run app.py` 직접 실행 시에는 첫 WebSocket 연결 전까지 app.py가 실행되지 않으므로 `import stream_server` 자동 시작이 작동 안 함. wrap script가 유일한 신뢰 가능한 방식
3. **같은 프로세스 보장** — Streamlit CLI를 `from streamlit.web.cli import main`으로 같은 프로세스에서 호출 (subprocess 분리 시 메모리 공유 안 됨)
4. **포트 :8503 결정** — :8502 macOS 차단 문제. 향후 모든 신규 환경에서 :8503 일관 사용

## 금지/확정 사항
- ❌ `streamlit run app/streamlit/app.py` 직접 실행 금지 — `python run_highlink.py` 사용
- ❌ MJPEG 포트 :8502 사용 금지 — macOS 차단 (:8503 사용)
- ❌ tornado_mjpeg.py 신규 의존 금지 — Streamlit 1.56+에서 silent fail (legacy 호환만 유지)
- ❌ 옵션 C(streamlit-webrtc) 도입 금지 — 프로덕션 전환 단계까지 보류
- ✅ 새 영상 표시 작업은 모두 :8503 standalone MJPEG 경유
- ✅ Phase C(멀티 카메라 확장) 작업 시 옵션 A(Starlette 미들웨어)로 마이그레이션 검토
