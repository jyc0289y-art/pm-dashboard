## 핵심 발견
- **LeadTech21** (12명·40.5억): 영국 Datapath 한국 출력카드 독점공급. 자체 MEDiARK + Datapath 재판매 듀얼. 한국 특허 9건. 사이트 사양 공개 매우 부족.
- **ESEICT** (91명·198억·자본금 16.65억): rino 9개 라인. **대통령상(2015) + GS 6+종**. 분산 서버 구조. 스마트시티 토털 솔루션.
- **ONEED** (규모 미공개): AiO-9000(자체) + Datapath VSN V3/Micro600 재판매 듀얼. 망분리 강조. Datapath Aetria/WallControl10 통합. 인증 명시 부족.
- **Nuricon** (33명·55.5억): 100% IP 자체. 분산병렬 렌더링·MC 코덱 NET 인증. **92,160px 가로 디스플레이엔진**. **영상감시장치 분야 조달청 우수제품 업계 최초(2025.08)**. 자체 주장 IP Wall 점유율 1위(~65%).

## 핵심 결정사항
- 30항목 = A.회사(3) + B.제품(3) + C.HW(6) + D.SW(5) + E.네트워크/HA(3) + F.보안(1) + G.인증(5, 현섭 강조) + H.레퍼런스(4)
- 인증 컬럼은 5종(KC/GS/조달우수+G-PASS/NET·EPC·녹색/ISO·해외)로 강화
- 검증 마크 도입: ✅ 제3자검증 / 📢 벤더공개 / ❓ 미확인
- 사이트 한계 발견: ESEICT SSL 인증서 오류 → curl + User-Agent 우회 사용
- Nuricon 사이트 동적 로딩 — 일부 페이지(인증/특허)는 직접 추출 불가, 회사연혁에서 보완
- ONEED 회사 규모(직원/매출)는 사람인 미등록 → "공개정보 한계"로 명시
