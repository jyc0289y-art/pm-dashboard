## Q2. HighLink와의 연결 — 사양 요구사항이 있나요?

만약 **(a) 도입 검토** 목적이라면, HighLink 관제실/시연용으로 필요한 사양을 알려주세요. 없으면 일반적인 비교만 진행합니다.

- 필요한 **출력 화면 수** (예: 2×2 = 4장? 3×3 = 9장? 5×N 비디오월?)
- 필요한 **입력 소스 수** (CCTV 동시 표시 개수)
- 화면 **해상도** (FHD / 4K / 8K)
- 입력 소스 종류 (RTSP/RTMP IP카메라, HDMI 로컬 입력, DP, 캡쳐보드, KVM 등)
- 환경 (관제실 상시운영 vs 시연용 가설치)
- 예산대 (천만원대 / 억대 / 미정)

> 기본값: **HighLink 멀티 카메라(P18.8.3.0 Phase C)와 정합 가정** — 3×3 그리드 9채널, FHD, RTSP IP카메라 9대 + 운영자 PC 1대, 관제실 상시운영, 예산 미정.
> 비고: 이게 맞으면 본 조사에서 "HighLink 적합도" 컬럼을 별도 추가합니다.
